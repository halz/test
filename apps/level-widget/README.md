# Level ウィジェット（Android）

Level Lock / Level Bolt を **ホーム画面のウィジェットから操作** するための Android アプリです。

## なぜこういう作りなのか

Level のアプリには外部から施錠 / 解錠を呼び出す API も Intent もありません。Matter が使えれば Google Home 経由で操作できますが、Matter アップグレードの提供期間が終わってしまった場合はその経路も使えません。BLE は独自の暗号化プロトコルなので直接叩くのも現実的ではありません。

残る唯一の手段が **アクセシビリティサービスで Level アプリの画面を代わりに押す** 方式です。このアプリはそれをやります。

Level のボタンは独自描画で、アクセシビリティのクリックイベントも要素の識別情報も一切出しません。そのため **画面上の位置と押す長さを 1 回だけ覚えさせる** 作りです。アクセシビリティサービスは追加の権限なしで `TYPE_ACCESSIBILITY_OVERLAY` の窓を出せるので、Level アプリの上に透明な窓を重ね、そこで押された位置と押していた長さを実測して記録します。

Level のボタンは 1 つで施錠と解錠が切り替わるので、**ロックごとにボタンは 1 つ**です。ロックは複数登録できます。

## インストール

最新の debug APK は Release **level-widget-latest** から取得できます: https://github.com/halz/test/releases/tag/level-widget-latest

## セットアップ

1. APK をインストールして「Level ウィジェット」を開く
2. **ユーザー補助**: 「アクセシビリティ設定を開く」→「Level ウィジェット」をオン
3. **対象アプリ**: 「対象アプリを選ぶ」で Level のアプリを選択
4. **ロック**: 「ロックを追加」で名前をつけ、以下を設定
   - **ボタンを覚える**: Level アプリが開き、画面の上端に帯が出る → 目的のボタンが見える画面まで操作 → 帯の「ここから」を押す → **ボタンの位置を、いつもと同じ長さで押す**（この操作は Level アプリには届きません）→ `ボタン: (540, 1200) / 1.8 秒の長押し` のように記録される
   - **Bluetooth 機器**（任意）: 圏内かどうかをウィジェットに出したい場合に紐づける（後述）
   - **テスト**: ウィジェットと同じ動作を確認
5. ホーム画面を長押し → ウィジェット → 「Level ウィジェット」を配置

### 「アプリはアクセスを拒否されました」と出る場合

Android 13 以降の「制限付き設定」です。ストア以外から入れた APK はユーザー補助を自分で有効化できません。端末側で一度だけ解除します。

1. 拒否ダイアログを閉じる
2. 設定 → アプリ → 「Level ウィジェット」（「すべてのアプリを表示」が要る場合あり）
3. アプリ情報の右上の ⋮ → **「制限付き設定を許可」**
4. 画面ロックで本人確認
5. 設定 → ユーザー補助 → インストール済みアプリ → 「Level ウィジェット」をオン

⋮ にその項目が出ないときは、先にユーザー補助側でオンにしようとして拒否ダイアログを出してからアプリ情報に戻ってください。Android 14 以降は、その権限を要求した直後だけメニューに現れます。それでも出ない場合は PC から `adb install -i com.android.vending -r level-widget-debug.apk` で入れ直すと外れることが多いです。

## 動作

ウィジェットにはロックが 1 行ずつ並びます。行を押すと **長押し確認の画面** が出るので、リングが 1 周するまで押し続けると実行されます。途中で離すと中止です。

> ウィジェットのボタン自体は長押しできません。ランチャーが長押しを移動 / リサイズに使うため、RemoteViews に長押しの API がないからです。確認用の画面を挟むことで、誤操作の防止と長押しの手触りを両立させています。

実行中は Level アプリを前面に出し、記録したボタンが押せる状態になるまで最大 15 秒待ってから、記録した長さだけ押し続けます。その間、Level アプリの上に進捗のオーバーレイを出します。結果（`操作しました（12:34）` など）はウィジェットの行に表示されます。

### Bluetooth 圏内の濃淡

ロックに Bluetooth 機器を紐づけると、**その機器のアドバタイズが直近 5 分以内に見えているロックは濃く、見えていないロックは薄く**表示されます。機器を紐づけていないロックは常に濃いままです（未設定を「圏外」と見せないため）。

スキャンは `BluetoothLeScanner.startScan(filters, settings, PendingIntent)` で OS に渡し、ハードウェアのフィルタで省電力に動かします。ロックと通信はせず、アドバタイズが見えるかどうかだけを見ます。ウィジェットの `⟳` を押すとスキャンを張り直して再描画します。

**うまくいかない可能性**: Level のロックがプライバシー保護でアドレスをランダム化（RPA）している場合、アドレスでの紐づけは効きません。「Bluetooth 機器」の選択画面に実際のスキャン結果（名前 / アドレス / 電波強度）が出るので、そこで判別できます。

## 制約と注意

- **ウィジェットからの操作は長押し確認だけで実行されます。** 端末に画面ロックをかけておいてください。
- Level アプリの画面レイアウトが変わると、位置がずれるので記録し直しが必要です。
- 複数のロックを登録した場合、Level アプリが別のロックの画面で開くと違うボタンを押す可能性があります。各ロックの記録は、そのロックが表示される画面の位置として取ってください。
- 解錠は Level アプリが錠前と通信できる距離にいることが前提です。アプリ側が失敗しても、このアプリはボタンを押したところまでしか分かりません。
- アクセシビリティサービスは対象アプリを限定していません（対象アプリを設定画面で選べるようにするため）。
- Google Play の制限により、この用途のアクセシビリティサービスはストア配布できません。APK を直接インストールして使います。

## ビルド

```bash
cd apps/level-widget
./gradlew test assembleDebug   # app/build/outputs/apk/debug/app-debug.apk
```

Android SDK（compileSdk 34 / JDK 17）が必要です。CI は `.github/workflows/level-widget-apk.yml` で同じコマンドを実行し、Release **level-widget-latest** に APK を置きます。上書きインストールのための固定署名キーはフリートコンソールの APK と同じ Secrets（`FLEET_KEYSTORE_B64` / `FLEET_KEYSTORE_PASSWORD`）を使います。
