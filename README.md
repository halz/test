# Mac Remote — Android から Mac の画面共有に接続する VNC クライアント

iOS の「Screens」のように、Android 端末から Mac の「画面共有」へインターネット経由で接続するアプリです。接続経路には [Tailscale](https://tailscale.com) を使い、どこからでも自宅・職場の Mac に安全に届きます。Galaxy Z Fold 8 のカバースクリーン / メインスクリーンの両方に対応したレスポンシブ UI です。

## 構成

| モジュール | 内容 |
|---|---|
| `:rfb` | 純 Kotlin/JVM の RFB (VNC) プロトコル実装。Android 非依存で、JVM 単体でテスト可能 |
| `:app` | Jetpack Compose の Android アプリ本体 |

`:app` は Android SDK がある環境でのみ Gradle に include されます (`settings.gradle.kts`)。SDK のない CI コンテナでも `gradle :rfb:test` が動きます。

### 実装済みプロトコル

- RFB 3.7 / 3.8 ハンドシェイク
- 認証: VNC パスワード認証 (type 2) と **Apple Remote Desktop 認証 (type 30, DH+MD5+AES-128)** — Mac のユーザ名+パスワードでログイン可能
- エンコーディング: Zlib / CopyRect / Raw + DesktopSize
- 入力: マウス (クリック / ドラッグ / 右クリック / スクロール)、キーボード (X11 keysym + Unicode keysym)

## Mac 側の準備

1. **システム設定 → 一般 → 共有 → 画面共有** をオンにする
2. macOS 14 以降で「高パフォーマンス」モードの選択肢が出る場合は**標準モード**を使う (高パフォーマンスモードは VNC 非互換の独自プロトコルです)
3. 認証方法は 2 通り:
   - **Mac のユーザ名+パスワードで入る** (推奨): 追加設定は不要。アプリの接続先設定で「ユーザ名」を入力する
   - **VNC パスワードで入る**: 画面共有の詳細設定で「VNC 使用者が画面を操作することを許可」を有効にしてパスワードを設定し、アプリでは「ユーザ名」を空にする
4. Mac に [Tailscale](https://tailscale.com/download) をインストールしてログインする

## Android 側の準備

1. [Tailscale Android アプリ](https://play.google.com/store/apps/details?id=com.tailscale.ipn) をインストールし、同じ Tailnet にログインして VPN を有効にする
2. 本アプリをインストールし、「＋」から接続先を登録する
   - ホスト: Mac の MagicDNS 名 (例 `my-mac.tail1234.ts.net`) または Tailnet IP (`100.x.y.z`)
   - ポート: `5900` (既定)
   - ユーザ名: Mac ログインで入るなら Mac のアカウント名。VNC パスワード方式なら空欄
   - パスワード: 上で選んだ方式のパスワード (Android Keystore で暗号化して保存されます)

## 操作方法

### ダイレクトモード (既定)

| 操作 | 動作 |
|---|---|
| 1 本指タップ | クリック (タップした位置へポインタが移動) |
| 1 本指ドラッグ | 表示のパン (Mac には送られない) |
| ダブルタップ → そのままドラッグ | 左ボタンドラッグ (選択・ウィンドウ移動) |
| 長押し | 右クリック |
| 2 本指上下ドラッグ | スクロール |
| ピンチ | ズーム |

### トラックパッドモード (ツールバー「TP」で切替)

ノート PC のトラックパッドのような相対移動方式。指を動かすとカーソルが相対的に動き、タップでカーソル位置をクリックします。カーソルが画面端に近づくと表示が自動追従します。ダブルタップドラッグ・長押し右クリック・2 本指スクロール・ピンチズームはダイレクトモードと同じです。

### マルチタッチジェスチャ (両モード共通)

| ジェスチャ | 既定の動作 |
|---|---|
| 2 本指タップ | 右クリック |
| 3 本指 上スワイプ | Mission Control |
| 3 本指 下スワイプ | アプリケーション Exposé |
| 3 本指 左/右スワイプ | 右/左のデスクトップへ移動 |
| 3 本指タップ | キーボード表示切替 |
| 4 本指 下スワイプ | デスクトップを表示 |
| 4 本指タップ | Spotlight |
| 4 本指 上/左/右スワイプ | 未割り当て |

割り当ては接続先一覧の「⋮ → 設定」で変更できます。選べるコマンドは Mission Control・Exposé・デスクトップ切替・アプリ切替 (⌘Tab)・Spotlight・コピー/ペースト・スクリーンショット・戻る/進む・ウィンドウ操作・右クリックのほか、アプリ側の操作 (キーボード表示、トラックパッドモード、Android から貼り付け、全体/フィル表示) です。「なし」を選ぶとそのジェスチャは無効になります。「既定に戻す」で全て初期値へ戻せます。

### ツールバー

| ボタン | 動作 |
|---|---|
| TP | トラックパッドモード切替 (設定は保存されます) |
| 貼付 | Android のクリップボードを Mac に貼り付け。英数字は VNC クリップボード + Cmd+V、日本語などはキー入力として送信 |
| ファイル | SFTP ファイルブラウザを開く (下記「ファイル送受信」) |
| 解像度 | 表示解像度の選択 (下記) |
| 全体 / フィル | 全体 = 画面全体を表示 (上下に黒帯)。フィル = 端末画面いっぱいに拡大 (左右は見切れ、パンで移動) |

キーボード (⌨)・修飾キー (⌘⌃⌥⇧)・Esc/Tab/矢印キーは**画面下部のバー**にあります (修飾キーは次のキー 1 回に適用)。キーボードは予測変換の変換中の文字もリアルタイムで Mac へ送られ、日本語変換は確定時に打ち直されます。

Mac 側でコピーしたテキストは自動的に Android のクリップボードへ同期されます (VNC の仕様上 Latin-1 のみ。日本語は化けます)。

## マルチタブセッション

複数の Mac に同時接続できます。接続中にツールバーの「一覧」(または Android の「戻る」) で接続を維持したまま一覧へ戻れます。接続中の Mac には「● 接続中」バッジが付き、タップすると即座に再開します。別の接続先をタップすると 2 本目のセッションが開き、画面左下にタブが現れます。タブをタップで切替、選択中のタブをもう一度タップ (✕) で切断、「＋」でさらに追加できます。

## バックグラウンドでの接続維持

セッション接続中はフォアグラウンドサービス (通知「Mac に接続中」) が動き、他のアプリに切り替えても接続が維持されます。バックグラウンドのまま一定時間 (既定 15 分、「⋮ → 設定」で変更・無効化可) が経過すると全セッションを自動切断します (アプリを見ている間は切れません)。通知はすべてのセッションを切断すると消えます。初回起動時に通知の許可を求められます (拒否しても接続維持自体は機能します)。それでも切断される場合は、Android の設定でこのアプリの電池最適化を「制限なし」にしてください。

## ファイル送受信 (SFTP)

ツールバーの「ファイル」から Mac のファイルを閲覧できます。ファイルをタップするとダウンロード、「↑」ボタンで Android のファイルを現在のフォルダへアップロードします。

- Mac 側で「システム設定 → 一般 → 共有 → **リモートログイン**」をオンにしてください
- プロファイルに**ユーザ名**が必要です (SSH 認証にプロファイルのユーザ名/パスワードを使用)
- ホストキー検証は行いません (Tailscale トンネル内での使用前提)

## 設定のエクスポート / インポート

接続先一覧の「⋮」メニューから、全接続先を JSON ファイルにエクスポート / インポートできます。機種変更やバックアップに使えます。**エクスポートには接続パスワードが平文で含まれる**ため、ファイルの取り扱いには注意してください。

## 表示解像度の最適化

Retina Mac のフル解像度 (例 2880x1800) をそのまま扱うとメモリと描画負荷が大きいため、受信した画面を端末側で間引いて表示できます。

- **自動 (既定)**: いま使っている画面 (Z Fold のカバー / メイン) のサイズに合わせて最適な間引き率を自動選択。折りたたみ状態を切り替えると自動で再計算されます
- **フル / 1/2 / 1/3**: 手動で固定

※ Mac 本体の画面解像度そのものは VNC プロトコルからは変更できません (macOS が対応していないため)。この設定は端末側の表示・処理の最適化です。

## ビルド

Android Studio でそのまま開くか:

```bash
./gradlew :app:assembleDebug     # 要 Android SDK
./gradlew :rfb:test              # プロトコル層のテスト (SDK 不要)
```

`:rfb` の統合テストは `x11vnc` / `Xvfb` / `xdotool` があれば実サーバに接続して検証し、なければ自動でスキップします。

## 既知の制限

- 日本語入力は Android 側 IME で確定した文字を Unicode keysym として送るベストエフォート方式です。Mac 側アプリによっては取りこぼしがあります
- macOS はカーソルを画面に描画しないことがあるため、最後にタップした位置をローカルのリングで表示しています (Cursor 擬似エンコーディングは未対応)
- ARD 認証の DH 512bit + MD5 は Apple 側仕様であり暗号強度は弱いため、**Tailscale トンネル内での使用を前提**としています。画面共有ポートをインターネットに直接公開しないでください
- フォアグラウンドサービスで接続を維持しますが、メーカー独自の強力な電池管理では稀に切断されることがあります (再接続ボタンでワンタップ復帰)
