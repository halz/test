# Level ウィジェット（Android）

Level Lock / Level Bolt を **ホーム画面のウィジェットから 1 タップで施錠 / 解錠** するための Android アプリです。

## なぜこういう作りなのか

Level のアプリには外部から施錠 / 解錠を呼び出す API も Intent もありません。Matter が使えれば Google Home 経由で操作できますが、Matter アップグレードの提供期間が終わってしまった場合はその経路も使えません。BLE は独自の暗号化プロトコルなので直接叩くのも現実的ではありません。

残る唯一の手段が **アクセシビリティサービスで Level アプリの画面を代わりにタップする** 方式です。このアプリはそれをやります。

Level アプリの内部 ID はこちらからは分からないので、**最初に 1 回だけ実際のボタンを押して覚えさせる**（記録する）作りにしてあります。記録するのは押されたビューの `viewIdResourceName` / `contentDescription` / `text` / 画面上の座標で、再生時はこの順に優先して一致するノードを探し、見つかればクリック、どれも一致しなければ記録した座標をタップします。

## セットアップ

1. APK をインストールして「Level ウィジェット」を開く
2. **ユーザー補助**: 「アクセシビリティ設定を開く」→「Level ウィジェット」をオン
3. **対象アプリ**: 「対象アプリを選ぶ」で Level のアプリを選択
4. **施錠ボタン**: 「覚えさせる」を押す → Level アプリが開くので、施錠ボタンを 1 回押す（記録されるとトーストが出る）
5. **解錠ボタン**: 同様に「覚えさせる」→ 解錠ボタンを 1 回押す
6. ホーム画面を長押し → ウィジェット → 「Level ウィジェット」を配置

「テスト」ボタンでウィジェットと同じ動作を確認できます。

## 動作

ウィジェットのボタンを押すと、Level アプリを前面に出し、記録したボタンが画面に現れるまで最大 15 秒間 0.5 秒おきに探して押します。結果（`施錠しました（12:34）` / `施錠のボタンが見つかりませんでした` など）はウィジェット下部に表示されます。

## 制約と注意

- **ウィジェットは確認なしで解錠します。** 端末に画面ロックをかけておいてください。
- Level アプリの画面デザインやボタンのラベルが変わると、記録し直しが必要です。
- 解錠は Level アプリが錠前と BLE で通信できる距離にいることが前提です。アプリ側が失敗した場合、このアプリはそれを検知できません（ボタンを押したところまでしか分かりません）。
- アクセシビリティサービスは対象アプリを限定していません（対象アプリを設定画面で選べるようにするため）。他のアプリの画面内容を読む処理は入れていませんが、権限としては強いものです。
- Google Play の制限により、この用途のアクセシビリティサービスはストア配布できません。APK を直接インストールして使います。

## ビルド

```bash
cd apps/level-widget
./gradlew test assembleDebug   # app/build/outputs/apk/debug/app-debug.apk
```

Android SDK（compileSdk 34 / JDK 17）が必要です。CI は `.github/workflows/level-widget-apk.yml` で同じコマンドを実行し、Release **level-widget-latest** に APK を置きます。上書きインストールのための固定署名キーはフリートコンソールの APK と同じ Secrets（`FLEET_KEYSTORE_B64` / `FLEET_KEYSTORE_PASSWORD`）を使います。
